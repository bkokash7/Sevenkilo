1. Scope

This notice covers the sevenkilo.com website. Each of our applications carries its own privacy policy describing how that specific app handles information, and those policies govern the apps rather than this one.

This is a static website. It has no accounts, no login, no contact form, and no comment system. We do not set cookies, run analytics, or use advertising or tracking scripts of any kind.

3. Fonts

Typefaces are loaded from Google Fonts. Your browser requests those files from Google's servers, which means Google receives your IP address as part of that request. This is standard for web fonts and happens on most websites you visit.

4. Hosting

The site is hosted by a third-party static hosting provider which may keep standard server logs, including IP addresses and requested pages, for security and operational purposes.
